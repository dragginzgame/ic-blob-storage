# Single-document pinning exception adoption

Pending compatible **0.19.4** adopts Shared Tooling's committed 0.1.38 fix at
`926a20606591214ab29faa236b0b584e4857439e`, using the canonical exporter from an
isolated clean checkout. The owner's uncommitted VERSION bump is excluded;
the snapshot commit and hashes identify the adopted bytes, not a release claim.

one fully validated array. Multiple documents previously let schema admission
and finding suppression select different inputs. Valid single-array catalogs
remain accepted. Blob currently has no exception catalog.
