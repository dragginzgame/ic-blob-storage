upload exposure and installation evidence derivation are internal. Their fresh
memory preflights, synchronous validation, IC rollback requirements and restored
fences are unchanged. Production certificate callers use `inspect_installation`
and `issue_installation`; the latter still commits possible exposure before its
plain reply and requires synchronous replicated execution with trap propagation.

Historical exposure inspection remains public and grants no issuance authority.

The non-default `test-support` feature and unit-test configuration own the
transient reference aggregate, heap enrollment state and its three read adapters.
Shared passive views, limits, pure checks and durable records stay model-owned.
The old aggregate path is removed. Only the unpublished admission/storage probes
select the feature; their component construction, simulated evidence, write traps
and resource observations use the explicit support boundary. Production builds
must exclude this feature, including Cargo feature unification from selected probes.
This preserves independent accounting comparisons without a second production owner.
